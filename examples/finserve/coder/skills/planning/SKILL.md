# Planning

Use `write_todos` with 3–8 concrete steps:

1. Discover schema (`postgres__list_tables` / `postgres__get_schema`).
2. Query tenant-scoped `portfolios`.
3. Write the pandas/numpy program (weights, sums, Monte Carlo, etc.).
4. `execute()` the full program.
5. Fix failures and re-run.
6. Report numbers from the query + script output.

Do not skip the SQL fetch and invent holdings.
