# Hosts and Routing Reference

This page lists the public hostnames configured in `values.yaml` and the internal Kubernetes ClusterIP service names generated by the Helm chart.

## Public Hostnames

Configured via `gateway.hosts.*` in `values.yaml`. These are the only endpoints published to the internet (or to your internal ingress network).

| Value Key | Default Example | Purpose |
| :--- | :--- | :--- |
| `gateway.hosts.agents` | `agents.example.com` | The Agent Protocol front door. Routes `X-Graph-ID` to workers. |
| `gateway.hosts.langfuse` | `langfuse.example.com` | Langfuse Web UI and API. |
| `gateway.hosts.aiGateway` | `ai-gateway.example.com` | (Opt-in) Direct access to the `/v1` proxy. Usually left empty for internal-only intercept. |

## Internal Services (ClusterIP)

These services are only resolvable from inside the Kubernetes cluster. The `{release}` prefix corresponds to your Helm release name (e.g., `zelkor-platform`).

| Internal Service Name | Port | Purpose |
| :--- | :--- | :--- |
| `{release}-aegra` | 8000 | Platform Aegra. The default backend for unmatched `X-Graph-ID` traffic. |
| `{release}-mcp` | 80 | The unified MCP gateway. Resolves internal tool routing and injects secrets. (ExternalName) |
| `{release}-mcp-postgres` | 8080 | Native Postgres MCP server. |
| `{release}-mcp-qdrant` | 8080 | Native Qdrant MCP server. |
| `{release}-mcp-sandbox` | 8080 | Sandbox execution coordinator. |
| `{release}-ai-gateway` | 80 | Envoy AI Gateway `/v1` proxy for LLM intercept. (ExternalName) |
| `{release}-nemo` | 8000 | NeMo Guardrails intercept server. |
| `{release}-langfuse` | 3000 | Langfuse UI and telemetry ingestion. |
